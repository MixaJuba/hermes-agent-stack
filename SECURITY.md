# Безпека й відповідальне повідомлення про проблеми

Цей репозиторій публічний, але Telegram-бот, Oracle VM, ключі провайдерів, приватний age recovery identity і резервні копії — **не публічні**.

Не додавайте до issues, PR, комітів, чатів чи тестових файлів реальні ключі, токени, паролі, cookies, SSH-ключі, OCI identifiers, конфіденційні журнали, приватний recovery record або повні Hermes backup ZIP. `.gitignore` не замінює перевірку секретів.

Якщо помітили вразливість, **не створюйте публічного опису експлуатації**. Перевірте, чи власник увімкнув GitHub **Security → Report a vulnerability** для приватного повідомлення; доступність цього механізму тут не стверджується. Якщо не ввімкнув, погодьте безпечний приватний канал із власником поза публічними issues.

Будь-які зміни production, IAM, secrets, провайдерів та backup/restore потребують окремого керованого gate. [AGENTS.md](AGENTS.md) · [PROJECT_STATE.md](PROJECT_STATE.md).
